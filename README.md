# منصة BMO التفاعلية

منصة عربية تفاعلية مستوحاة من روح BMO ووقت المغامرة، تجمع بين الألعاب القصيرة والمحادثة السياقية واستكشاف المحتوى الخارجي في واجهة RTL هادئة وسريعة.

## البنية

تعتمد الواجهة على React وTypeScript وVite وTailwind، بينما تُنفّذ كل الاتصالات الحساسة من خلال دوال Vercel Serverless داخل مجلد `api/`. تُستخدم Supabase لحفظ نتائج الألعاب والمصادقة المجهولة ومخزن الأصول الخاص. تُستدعى Firecrawl من دالة البحث الخادمية فقط، ولا يظهر مفتاحها في المتصفح.

## الألعاب

تتضمن النسخة الحالية ثلاث تجارب أصلية: «مسارات المملكة» وهي مغامرة اختيارية متعددة المشاهد، و«شفرة BMO» وهي تحدي ترتيب إشارات، و«نبضة السرعة» وهي لعبة رد فعل تعتمد على التقاط أهداف متحركة خلال وقت محدود. تُرسل النتيجة والسياق إلى دالة التقدم بعد النجاح.

## التشغيل المحلي

انسخ `.env.example` إلى `.env.local` واملأ القيم المناسبة. الواجهة تعمل مباشرة عبر Vite، أما دوال `api/` فتُشغّلها Vercel Serverless في بيئة النشر أو عبر أداة Vercel المحلية. بعد ذلك شغّل:

```bash
npm install
npm run dev
```

وللتحقق من نسخة الإنتاج:

```bash
npm run check
npm run build
```

## Supabase

توجد الترحيلات في `supabase/migrations/`. شغّل الترحيلين على مشروع Supabase المرتبط قبل تفعيل حفظ النتائج. يجب وضع `SUPABASE_SERVICE_ROLE_KEY` في بيئة Vercel فقط، بينما يُسمح للمتصفح باستخدام `VITE_SUPABASE_PUBLISHABLE_KEY` حصراً.

## Vercel

إعداد `vercel.json` يحدد مجلد `dist/public` كمخرج البناء ويترك مسارات `/api/*` للدوال الخادمية. أضف متغيرات `SUPABASE_URL` و`SUPABASE_SERVICE_ROLE_KEY` و`FIRECRAWL_API_KEY` و`OPENAI_API_KEY` في بيئة Vercel قبل النشر. عند غياب Firecrawl يعرض البحث نتائج تجريبية ثابتة، وعند غياب النموذج تعود المحادثة برسالة احتياطية بدلاً من انهيار الواجهة.

## ملاحظات الجودة

تم تشغيل فحص TypeScript وبناء الإنتاج بنجاح، وتنظيف مسار Express القديم وإضافات Replit وتبعيات Drizzle غير المستخدمة. كما تم اختبار الصفحة الرئيسية، التنقل، الألعاب الثلاث، حفظ نتيجة شفرة BMO، مؤقت لعبة رد الفعل، واجهة المحادثة، وقسم البحث الخارجي من خلال نسخة المعاينة المحلية. عند غياب دالة البحث محلياً تعرض الواجهة خيارات آمنة احتياطية بدلاً من مساحة فارغة. سجل الاختبار التفصيلي موجود في `qa-notes.md` و`visual-qa.md`.
